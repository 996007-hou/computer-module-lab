# 计算机模块实验室

计算机模块实验室是一款用 Godot 和 GDScript 编写的 Windows 教学软件，把操作系统课程中的概念做成可以逐步操作的实验。

- **学生课前预习**。按教材章节进入实验，跟着步骤观察系统状态怎样变化，再改动参数、查看结果，用练习检验理解。
- **教师课堂讲解**。可以投屏演示，逐步推进并停在关键状态，带学生看清每一步发生了什么。需要按自己的教学安排调整讲解、实验展示或规则时，可以把[个性化修改指南](CODE_GUIDE.md)交给 AI，按章号定位文件和函数。

## 启动

下载并解压 [Godot 4.4.1 Windows 64 位版](https://github.com/godotengine/godot/releases/tag/4.4.1-stable)，将 `Godot_v4.4.1-stable_win64.exe` 和 `Godot_v4.4.1-stable_win64_console.exe` 放入仓库根目录的 `tools` 文件夹。双击 `启动实验室.bat` 打开软件，也可以用 Godot 导入 `project.godot` 并按 F5 运行项目。

## 两种开始方式

- 首页“按教材章节学习”：九章都有交互实验。第 1～3、8、9 章进入后可在“动手实验”和“知识点与练习”之间切换。
- 首页“开始组合模块”：点击模块后，它会移动到组合工作区并从模块库中消失；在工作区点击“移除”可放回。组合完成后选择学习主题，也可以使用一键组合示例。首页还可直接进入内存分配。

## 已实现的实验

- 第 1～3 章：补充系统调用与设备中断、进程控制块 PCB、用信号量协调水果盘。第 8 章涵盖 I/O 缓冲、DMA、中断和磁盘块，第 9 章涵盖目录、文件索引分配和空闲位图。每个知识点有分步示意和带解释的练习。
- 第 1、2 章动手实验：对比缓存命中与磁盘读取。操作单 CPU 的就绪、运行和阻塞队列，查看执行指令和保存现场对 PCB 的影响。第 2 章的新手引导展示 P1 和 P2 如何换班，自由操作时也提示下一位可调度的进程。
- 第 3 章水果盘：操作生产者和两类消费者，观察单格盘子的占用、阻塞、唤醒和取用。新手引导展示两个消费者如何等待和取到各自的水果。
- 第 8 章缓冲区可分两步观察设备放入和程序取走，也可设定拍数直接跑到结束。速度对比图用同样的容量和设备速率对比两个读取速度，并标出设备等空位、程序等数据的情况。
- 第 9 章文件块：在 12 个模拟磁盘块中创建、扩展或删除文件，观察文件索引和空闲位图同步变化。

- 第 3 章信号量：组合“进程 + 操作系统 + 资源”，或从第 3 章点击“信号量 P / V 实验”。“开始课堂示范”演示两进程轮流使用资源。“投屏大字”放大关键状态，并给实验腾出整个工作区。自由操作时，进程被唤醒后需手动选择“调度并进入”。

- 第 4 章处理机调度：组合“进程 + 操作系统 + CPU”。输入到达时间和运行时间，逐步比较 FCFS、非抢占 SJF、HRRN、抢占 SRTF 和 RR；显示每步候选进程及比较依据，支持时间片和逐进程指标。时间为整数，同一时间单位，忽略切换开销。SRTF 同剩余时间时继续运行当前进程；RR 时间片边界先加入新到进程，再将未完成进程放回队尾。
- 第 5 章银行家算法：组合“进程 + 操作系统 + 资源”。可在矩阵中直接修改最大需求和已分配量，增减进程（1～6 个）和资源（1～4 类），也可修改资源总量和请求；支持单独检查当前状态或模拟请求，逐步观察 Work、Finish、资源归还记录和安全序列。模拟请求不会更新表格或真实系统。找不到安全序列不等于此刻已经死锁。
- 第 6 章动态分区：组合“程序 + 操作系统 + 内存”。支持首次适应、最佳适应、最坏适应，分配、回收、相邻合并、紧凑及外碎片。可以输入整数或一位小数，选择 KB 或 MB。切换单位会用新单位解释当前数值，不自动换算；正数为空闲、负数为占用。预设“课堂：0.1 KB 碎片”以用户区起点为 0，不画系统区。选择算法后可直接分配，或通过自动演示和单步查看查找过程；算法选中的分区会高亮。
- 第 6 章基本分页：同一组内存模块中选择“基本分页”。程序大小和页大小按 1 KB = 1024 字节计算，可修改页表和逻辑地址（最多 32 个页框），逐步拆分地址、查询页框并计算物理地址。可选“自己算一算”并检查答案。“课堂 12 KB”对应照片中 12 KB 和 2 KB 的参数，页框位置为演示设定。这里是所有页已装入的基本分页，不模拟缺页。
- 第 6、7 章地址转换图解：在第 6 章主题列表选择“地址转换图解”，或在第 7 章实验标题旁选择“页、块、段图解”。可用固定示例对比分页、分段、段页式，修改地址后沿连线查表，观察物理位置和段内偏移越界提示。
- 第 7 章页面置换：组合“进程 + 操作系统 + 内存 + 外存”。输入页面访问序列及页框数，逐步比较 FIFO 和 LRU 的命中、缺页及置换，并显示页面先后顺序和换出依据。提供 Belady 示例：FIFO 下将页框从 3 改为 4 可观察缺页次数变化。初始页框为空；不模拟脏页写回和访问时间。

## 操作提示

每个实验支持返回主题；修改输入会重新计算。内存分配支持立即分配、自动演示、单步和重置。分页、调度、银行家算法和页面置换支持上一步、下一步、自动演示、直接看结果和重新开始；修改输入或返回上一步会暂停自动演示。分页的“自己算一算”模式会隐藏答案，直到检查或主动查看。长内容可以在实验区域内滚动。输入不符合模型限制时，界面会说明原因。

## 测试与资料

在终端运行 `运行检查.bat` 查看回归检查结果。`tests` 目录包含界面导航、分区、分页、调度、银行家算法、页面置换、演示控制和随机不变量检查。视觉检查脚本将截图保存到本地 `runtime` 文件夹。

“课堂资料与模型说明.md”记录照片与教材对应关系，以及简化和不确定之处。该软件是教学模拟，不读取或修改真实操作系统的调度或内存。
